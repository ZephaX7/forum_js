# BMW Community Forum

Application web de forum permettant aux utilisateurs de créer, consulter et commenter des discussions autour de la communauté BMW.

---

## Fonctionnalités

- Authentification utilisateur (inscription et connexion)
- Création de discussions avec catégories
- Consultation des discussions existantes
- Ajout de réponses aux discussions
- Interface web simple et fonctionnelle
- Stockage des données en base SQL

---

## Technologies utilisées

- Go (backend)
- HTML / CSS (frontend)
- JavaScript (interactions et appels API)
- Base de données SQL

---

## Installation

### Prérequis

- Go 1.20 ou supérieur

---

### Étapes

1. Se placer dans le dossier du projet

```bash
cd forum_js
```

2. Installer les dépendances

```bash
go mod tidy
```

3. Lancer le serveur

```bash
go run .
```

---

## Utilisation

1. Accéder au site
2. Créer un compte
3. Se connecter
4. Créer ou consulter des discussions
